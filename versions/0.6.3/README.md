# Soares Soluções 0.6.3

Atualização visual da tela de acesso sobre a base operacional 0.6.2.

- Ilustração de estoque fornecida pelo proprietário no lugar da foto pessoal.
- Logo Soares Soluções legível na tela de entrada e na navegação.
- Composição dividida, painel azul com degradê e botão de entrada em degradê azul.
- Mantidas as correções transacionais e o histórico das movimentações da 0.6.2.

Verificação: compilação Python dos módulos alterados; banco SQLite temporário com cadastro, transferência, entrada, ajuste de inventário, quatro eventos e PRAGMA integrity_check. A interface Windows e a aplicação do atualizador não foram executadas neste ambiente Linux sem servidor gráfico.

Os dados permanecem locais em %LOCALAPPDATA%/Soares Solucoes/soares_solucoes.db. Esta versão não sincroniza dados entre computadores ou filiais. O manifesto distribui código e imagens, sem banco de dados ou credenciais.
